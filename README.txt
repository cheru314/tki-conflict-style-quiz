# 갈등 대응 스타일 선택 진단 (비공식 교육용)

## 내용
- 모바일 반응형 웹페이지
- 20개의 새로 작성한 문항 쌍에서 A/B 중 하나를 선택하는 강제선택형
- 다섯 유형 점수와 주요 경향 해석 제공
- 응답은 브라우저 내에서만 계산하며 서버로 전송하지 않음

## 인터넷 공개 및 QR 코드
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` 및 `/(root)`를 선택해 저장합니다.
4. 생성된 공개 URL을 휴대폰에서 테스트합니다.
5. 그 URL을 QR 코드 생성 사이트(예: https://www.qrcode-monkey.com/)에 입력해 QR 이미지를 만듭니다.

## 중요
정식 TKI는 30개 문항 쌍으로 구성된 별도의 상용 평가도구입니다. 이 페이지는 TKI의 다섯 유형을 참고해 독자적으로 만든 비공식 교육용 자가성찰 도구로, 정식 문항·채점·규준·타당도를 재현하지 않습니다. 인사평가나 임상적 판단에 단독으로 사용하지 마세요.
